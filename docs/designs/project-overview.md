# 项目概览

最后更新：2026-04-05

## 背景

本项目旨在成为一个用于个人理财用例的 Local-First 记账应用。产品方向保持为：

- 快速的本地交互
- 可靠的离线行为
- 简单且可维护的架构
- 严格的金融正确性

## 当前状态

**阶段 1 已完成** ✅ - 本地账目流水记录功能已实现。

### 已实现功能

- ✅ 本地 SQLite 持久化存储
- ✅ 账目流水 CRUD（创建、读取、更新、删除）
- ✅ 收入/支出分类
- ✅ 货币金额使用整数存储（分为单位）
- ✅ 收支汇总显示
- ✅ 单元测试（107 个测试）
- ✅ 集成测试（22 个测试）
- ✅ E2E 测试框架（Maestro）

### 尚未实现

- 账户和类别管理
- 本地报表和可视化
- 云端数据同步
- 数据备份
- 身份验证

## 产品目标

- 提供一个离线时仍可使用的记账体验
- 将云端职责限制在稍后的备份和同步上
- 维护一个可以通过测试和文档安全演进的代码库

## 架构原则

### 1. Local-First

所有数据优先存储在本地 SQLite，云端同步是可选的次要功能。

### 2. 金融正确性

货币金额绝不使用浮点数，全部使用整数（分为单位）存储和计算。

### 3. 渐进式交付

小步快跑，持续验证。每个阶段都是可交付的产品增量。

### 4. 可测试性

核心业务逻辑与 UI 解耦，便于单元测试和集成测试。

## 当前公共 API

### 应用内部 API

应用使用本地 SQLite 存储，核心 API 包括：

- `LedgerEntryRepository` - 数据访问层
- `LedgerEntryService` - 业务逻辑层

### 服务端 API

- `GET /healthz` - 健康检查
- `GET /api/v1/bootstrap` - 启动元数据
