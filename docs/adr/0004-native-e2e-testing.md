# 原生端 E2E 验收

## 状态

Superseded

已由 [ADR 0007：独立原生构建与状态隔离](0007-dedicated-native-e2e.md) 替代。

## 背景

React Native 的原生组件、导航、深层链接和设备存储在 Web 上可能具有不同实现。只通过浏览器测试无法证明 iOS 或 Android 的真实用户流程可用。

同时，所有行为都依赖设备 E2E 测试会使反馈变慢，不适合验证大量领域边界。

## 决策

- Jest 单元和集成测试负责快速验证领域、数据访问、状态和组件行为
- Maestro 在模拟器或真机上验证关键原生用户流程
- Web 运行结果不能替代 iOS/Android 的 E2E 验收
- 当前 CI 运行快速检查；Maestro 由具备设备环境的流程执行

## 后果

- 原生行为由接近真实设备的环境验证
- 开发者需要在本地准备 Maestro 和模拟器或真机
- CI 可以持续运行快速的 Jest 和 Go 测试，原生 E2E 需要独立设备环境
- Web 仍可作为辅助运行目标，但其兼容性不驱动原生实现退化
